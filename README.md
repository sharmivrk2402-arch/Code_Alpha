📘 CGPA Calculator in C++

A simple CGPA Calculator program written in C++ that calculates the final CGPA based on grades and credit hours entered by the user.
This project is useful for students to understand functions, conditionals, loops, and input/output in C++.

✨ Features

Accepts multiple courses
Converts grades to grade points
Automatically assigns 1 credit for language subjects (Tamil & English)
Calculates:
Total Credits
Total Grade Points
Final CGPA
Displays PASS / FAIL result
Validates incorrect grade input

🛠️ Technologies Used

Language: C++
Concepts:
Functions
Conditional statements
Loops
Strings

User input/output
